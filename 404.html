HOW IT WORKS

A controlled path from source to sales action

Every stage has one responsibility. AI candidates cannot bypass Human Review.

  1. 01Public SourcesOfficial pages, filings and releases
  2. 02AI Candidate ExtractionSource-grounded claims, not approved truth
  3. 03Fact / Inference / UnknownWhat is known, interpreted or missing
  4. 04Human ReviewApprove, edit or reject every candidate
  5. 05Approved EvidenceTyped records with provenance
  6. 06Fit / Timing / ConfidenceFrozen deterministic rules
  7. 07ClassificationA / B / C / D plus Decision Reason
  8. 08Sales BriefEvidence, unknowns, risks and next action
Core boundary

LLM proposes Candidate Evidence. It does not calculate Fit, Timing, Confidence or Classification.

What the build demonstrates

  • Frozen Test data and one official run are preserved.
  • Agent Evidence and Human Evidence remain separate.
  • Scoring is deterministic, reproducible and append-only.
  • Errors, D abstentions and missed A accounts remain visible.

What it does not demonstrate

  • Gold labels were not produced by an independent human panel.
  • The extractor was recorded, not a live production LLM Provider.
  • Manual, Agent and Review timing measurements are not comparable.
  • No ROI, productivity or deal-conversion conclusion is valid.
